# 🏪 운세 편의점

**24시간 열려 있는 나의 운세 가게.**
사주팔자 · 오늘의 운세 · 일일 타로 · MBTI 결합 해석을 담은 웹 앱입니다.
엽전으로 매일 조금씩 사서 보는 편의점 컨셉으로 만들었습니다.
빌드 도구 없이 순수 HTML/CSS/JS로 만들어져 어디서든 바로 실행됩니다.

**🔗 배포 주소: https://gnuinu.github.io/saju/**

## 실행 방법

```bash
# 아무 정적 서버로 열면 됩니다
python3 -m http.server 8000
# → http://localhost:8000 접속
```

`index.html`을 브라우저에서 직접 열어도 동작합니다.

## 배포

`main` 브랜치에 푸시하면 `.github/workflows/deploy-pages.yml`이 자동으로
엔진 테스트를 돌리고 GitHub Pages에 배포합니다. 테스트가 실패하면 배포되지 않습니다.

### 최초 1회 필수 설정

저장소 **Settings → Pages → Source**를 **GitHub Actions**로 지정해야 합니다.

워크플로의 `configure-pages` 단계에 `enablement: true`가 있지만, Actions의 `GITHUB_TOKEN`으로는
Pages 사이트를 새로 **생성**할 수 없습니다(`Resource not accessible by integration`).
사이트가 한 번 만들어진 뒤부터는 이 단계가 기존 설정을 읽어오기만 하므로 그대로 통과합니다.

설정 후에는 Actions 탭에서 `Deploy to GitHub Pages` 워크플로를 `Re-run` 하거나
`main`에 아무 커밋이나 푸시하면 배포됩니다.

## 과금 구조 (엽전 시스템)

손님은 엽전으로 계산합니다. 광고를 보거나 매일 출석 도장을 찍으면 엽전이 쌓입니다.

- **획득**: 첫 방문 +30냥, 매일 출석 도장 +5냥, 광고 시청 +3냥 (일 3회)
- **사용**: 주간 운세, 심층 리포트, 타로 추가 뽑기
- **충전/정기권**: 계산대에 패키지 UI 준비됨 (결제 연동 전 "준비 중" 상태)

### 광고/결제 연동 지점

실제 서비스 전환 시 `js/store.js`의 두 함수만 교체하면 됩니다.

- `showRewardedAd(onComplete, onCancel)` — 현재는 5초 카운트다운 데모 모달(`AdPlaceholder`).
  AdMob/카카오 AdFit 등 리워드 광고 SDK 호출로 교체.
- `purchasePackage(pkgId, onSuccess, onFail)` — 현재는 "준비 중" 안내.
  인앱결제(IAP) 또는 PG 결제 모듈로 교체. 상품 정의는 `IAP_PACKAGES` 참조.

## 사주 계산 방식과 한계

- 일주: 율리우스 적일 기반 60갑자 (2000-01-01 = 무오일 검증)
- 년주: 입춘 기준 / 월주: 절기(節氣) 기준 / 시주: 일간 기준 오자시두법
- 23시 이후 출생은 다음날 자시로 처리, 한국 출생 시 태양시 −30분 보정 옵션
- **대운**: 양남음녀 순행 / 음남양녀 역행. 대운수는 순행이면 다음 절기까지,
  역행이면 이전 절기부터의 일수를 3으로 나눠 산출합니다 (성별 필수)
- **배우자성**: 남자는 재성(정재·편재), 여자는 관성(정관·편관) 기준
- **신살**: 년지·일지의 삼합국 기준 도화·역마·화개, 일간 기준 천을귀인
- 절기는 근사식을 사용하므로 절기 경계일(입춘 등) 전후 출생은 실제 만세력과 1일 차이가 날 수 있습니다
- 현재 **양력 입력만** 지원 (음력 변환은 로드맵)
