# 🏪 운세 편의점

**24시간 열려 있는 나의 운세 가게.**
사주팔자 · 오늘의 운세 · 일일 타로 · MBTI 결합 해석을 담은 웹 앱입니다.
엽전으로 매일 조금씩 사서 보는 편의점 컨셉으로 만들었습니다.
빌드 도구 없이 순수 HTML/CSS/JS로 만들어져 어디서든 바로 실행됩니다.

**🔗 배포 주소: https://gnuinu.github.io/saju/**

## 실행 방법

```bash
# 아무 정적 서버로 열면 됩니다
python3 -m http.server 8000
# → http://localhost:8000 접속
```

`index.html`을 브라우저에서 직접 열어도 동작합니다.

## 배포

`main` 브랜치에 푸시하면 `.github/workflows/deploy-pages.yml`이 자동으로
엔진 테스트를 돌리고 GitHub Pages에 배포합니다. 테스트가 실패하면 배포되지 않습니다.

> 이 저장소는 Pages 설정이 완료되어 있습니다. 포크해서 쓰실 경우에만 아래가 필요합니다.
> **Settings → Pages → Source**를 **GitHub Actions**로 한 번 지정해 주세요.
> Actions의 `GITHUB_TOKEN`으로는 Pages 사이트를 새로 *생성*할 수 없어
> (`Resource not accessible by integration`) 최초 1회는 수동 설정이 필요합니다.

## 과금 구조 (엽전 시스템)

손님은 엽전으로 계산합니다. 광고를 보거나 매일 출석 도장을 찍으면 엽전이 쌓입니다.

- **획득**: 첫 방문 +30냥, 매일 출석 도장 +5냥, 광고 시청 +3냥 (일 3회)
- **사용**: 주간 운세, 심층 리포트, 타로 추가 뽑기, 궁합 상세 풀이
- **충전/정기권**: 계산대에 패키지 UI 준비됨 (결제 연동 전 "준비 중" 상태)

### 광고/결제 연동 지점

실제 서비스 전환 시 `js/store.js`의 두 함수만 교체하면 됩니다.

- `showRewardedAd(onComplete, onCancel)` — 현재는 5초 카운트다운 데모 모달(`AdPlaceholder`).
  AdMob/카카오 AdFit 등 리워드 광고 SDK 호출로 교체.
- `purchasePackage(pkgId, onSuccess, onFail)` — 현재는 "준비 중" 안내.
  인앱결제(IAP) 또는 PG 결제 모듈로 교체. 상품 정의는 `IAP_PACKAGES` 참조.

## 사주 계산 방식과 한계

- 일주: 율리우스 적일 기반 60갑자 (2000-01-01 = 무오일 검증)
- 년주: 입춘 기준 / 월주: 절기(節氣) 기준 / 시주: 일간 기준 오자시두법
- 23시 이후 출생은 다음날 자시로 처리
- **절기**: 태양 겉보기 황경을 직접 계산(Meeus 천문알고리즘 + ΔT 보정)해 절기 **시각까지** 구합니다.
  근사식(壽星公式)을 쓰지 않으므로 입춘 등 경계일 출생도 정확합니다.
  같은 날이라도 절기 시각 전후로 년주·월주가 갈리는 것까지 반영합니다.
- **한국 표준시 역사 반영**: 표준자오선이 UTC+8:30이던 시기(1954-03-21~1961-08-09)와
  서머타임 시행 기간(1948~51, 1955~60, 1987~88, IANA tz database 기준)에 따라
  태양시 보정값을 30분 / 0분 / 90분으로 자동 조정합니다. 시주 정확도에 직결됩니다.
- **대운**: 양남음녀 순행 / 음남양녀 역행. 대운수는 순행이면 다음 절기까지,
  역행이면 이전 절기부터의 일수를 3으로 나눠 산출합니다 (성별 필수)
- **배우자성**: 남자는 재성(정재·편재), 여자는 관성(정관·편관) 기준
- **신살**: 년지·일지의 삼합국 기준 도화·역마·화개, 일간 기준 천을귀인
- **궁합**: 일지(배우자궁)·일간·오행·띠 네 축을 각 25점으로 봅니다.
  지지는 삼합/육합/충/원진/육해를, 천간은 천간합/충/상생/상극/비화를 판정하고,
  두 사주를 합쳤을 때의 오행 균형과 서로의 부족한 기운을 채워 주는 정도를 반영합니다.
- **음력**: 삭(신월) 순간을 Meeus 49장으로 계산해 초하루를 정하고,
  "동지는 11월에 든다 / 중기 없는 달이 윤달" 규칙으로 달 번호와 윤달을 판정합니다.
  한국 음력 기준인 KST(UTC+9)를 씁니다 (중국 음력은 UTC+8이라 가끔 하루 차이가 납니다).
  설날·추석·윤달 실측 대조 및 1930~2030년 양력↔음력 왕복 변환으로 검증했습니다.

### 남아 있는 한계

- 절기 **시각**은 저차항 급수를 쓰므로 실제와 수 분 차이가 날 수 있습니다.
  날짜 판정에는 영향이 없고, 절기 순간 ±10분 이내 출생자만 영향을 받습니다.
- 균시차(眞太陽時)는 적용하지 않고 평균태양시를 씁니다 (국내 만세력의 통상 관례).
- 1930년 이전 출생은 지원하지 않습니다 (입력 범위 제한).
